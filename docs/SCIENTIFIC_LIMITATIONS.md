# RamanAI 科学限制

1. `reference_label` 是数据库候选参考标签，不是独立矿物学真值；数据中也可能包含非矿物材料。
2. 余弦相似度和标签分数不是概率、置信度或诊断准确率。
3. 正式评价是固定 60 标签、冻结 Gallery 和 final-test 下的闭集检索评价；不能外推到全部矿物、
   所有仪器、采样条件或外部数据。
4. Sample_ID 是当前协议的隔离单位，不自动证明为经外部核实的独立物理标本。
5. 方法 A 对标签内全部 Gallery 光谱取最大余弦相似度，标签参考谱数量不均衡可能影响最大值分布。
6. 公共网格 300–850 cm⁻¹、0.5 cm⁻¹ 是工程试验设置，不是已证明普适最优的科研网格。
7. SG 窗口为 21 个采样点；原始采样间距不同意味着实际物理平滑宽度不同。
8. 线性插值不恢复仪器未采到的信息，也不允许外推或补零。
9. V1 的 half-prominence width 是 `peak_widths(rel_height=0.5)` 的半突出度宽度，不能无条件称为
   物理 FWHM。
10. 正式 final-test 结果产生后不得据此调参、换方法、改变 Gallery、删除不利样本或重选分组。

应用级 5,529 条候选参考谱用于交互检索，不等于正式评价使用的 724 条冻结 Gallery；UI 查询
结果不能替代科研评价。
