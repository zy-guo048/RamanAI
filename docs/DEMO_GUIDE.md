# RamanAI V1 验收演示指南

## 1. 演示目标

在约 5 分钟内展示 RamanAI V1 的真实单光谱分析流程：中英文切换、上传、预处理、候选峰检测、峰表、CSV 下载和突出度调节，并准确说明结果的科学边界。

## 2. 演示前准备

1. 确认项目虚拟环境依赖已安装。
2. 确认 `data/raw/sample_raw.txt` 存在且未被修改。
3. 在项目根目录运行测试：

   ```powershell
   .\.venv\Scripts\python.exe -m unittest discover -s tests -v
   ```

4. 启动 Streamlit：

   ```powershell
   .\.venv\Scripts\python.exe -m streamlit run app.py
   ```

5. 在浏览器中打开终端显示的本地地址。确认默认语言为简体中文，并保持 `prominence=1000.0`。

## 3. 五分钟演示流程

### 0:00–0:35 启动与系统定位

- 展示页面标题“RamanAI — 智能拉曼光谱分析系统”。
- 简述：系统用于单条拉曼光谱预处理和候选峰分析，不是已经验证的矿物分类器。
- 指出页面允许上传 `.txt`，并显示可调的候选峰突出度阈值。
- 指出标题行右侧的“⚙️ 设置 / Settings”按钮，说明系统支持简体中文和英语。

### 0:35–1:10 上传真实光谱并分析

- 点击上传控件，选择 `data/raw/sample_raw.txt`。
- 保持突出度默认值 `1000.0`，点击“开始分析”。
- 分析完成后展示文件名、数据点数和候选峰数量。
- 按当前自动化回归测试，该 Annite 样本在历史默认参数下应显示 8 个候选峰。若不是 8 个，停止把结果作为通过项，记录环境与文件差异并重新运行测试。

### 1:10–2:05 展示处理阶段

- 打开“本次分析参数（未自动优化）”，说明：
  - SG：`window_length=21`，`polyorder=3`；
  - AsLS：`lam=1e6`，`p=0.01`；
  - 寻峰：`prominence=1000`，`distance=10` 个采样点；
  - 峰宽：`rel_height=0.5` 的半突出度宽度；
  - 归一化：`max`。
- 依次展示原始光谱、SG 去噪光谱和 AsLS 基线校正光谱。
- 展示最大值归一化光谱，并强调归一化结果没有用于 `prominence=1000` 的寻峰。

### 2:05–2:45 展示候选峰与峰表

- 展示“AsLS 基线校正光谱上的候选峰”图，说明峰标记来自未归一化 corrected 光谱。
- 展示候选峰特征表中的峰位、校正后强度、突出度和半突出度宽度。
- 说明半突出度宽度不是无条件等同于物理 FWHM 的单峰拟合结果。

### 2:45–3:15 下载 CSV

- 点击“下载候选峰特征 CSV”。
- 说明文件名为 `sample_raw_candidate_peak_features.csv`，使用 UTF-8-SIG 编码。
- 如现场打开 CSV，确认包含：`Peak_ID`、`Position_cm-1`、`Intensity`、`Prominence`、`Half_Prominence_Width_cm-1`、`Left_cm-1`、`Right_cm-1`、`Width_Height`。
- 强调下载在内存中生成，不会自动覆盖 `results/`。

### 3:15–3:55 切换中文和英文

- 点击页面右上方“⚙️ 设置 / Settings”，展示由 `st.dialog()` 打开的设置窗口。
- 选择 `English / 英语`，确认页面标题、上传区域、突出度控件、参数说明、图表标题与坐标轴、图例、峰特征表及下载按钮切换为英语。
- 指出上传文件、`prominence=1000` 和已有 8 个候选峰结果仍保留，语言切换没有重新执行光谱 Pipeline。
- 再次打开设置窗口并选择 `简体中文 / Simplified Chinese`，确认界面立即恢复中文。
- 说明 CSV 的原始字段名称、数值与计算过程不受界面语言影响。

### 3:55–4:30 演示突出度影响

- 将同一 Annite 样本的突出度从 `1000.0` 改为 `100.0`，再次点击“开始分析”。
- 当前回归测试预期候选峰数由 8 变为 17，可用于直观说明阈值敏感性。
- 指出结果区显示本次实际使用的 `prominence=100`，旧的 8 峰结果不会继续保留。
- 说明低阈值可能引入噪声峰，因此所有结果均称为“候选峰”，不能把峰数增加解释为分析质量必然提高。

如果现场另有经过确认的低强度 `.txt` 光谱，可在格式满足要求时上传，并按其 corrected 强度尝试较低阈值；项目没有随附一条专门的低强度真实演示文件，因此不要承诺固定峰数。自动化测试仅用合成低强度光谱验证了：默认 1000 为零峰、降低到 10 后可出现候选峰。

### 4:30–5:00 总结科学边界

- 当前输出用于预处理检查和候选峰筛选。
- `distance=10` 的单位是采样点，不是 cm⁻¹。
- 最大值归一化主要用于显示和后续分析，不改变未归一化强度上的突出度定义。
- 候选峰尚未完成矿物特征归属；12 条历史光谱也不能证明材料分类准确率。
- 当前 V1 没有矿物分类模型、参考谱库相似度匹配或约 11,415 条外部数据集处理功能。

## 4. 可选异常演示

如时间允许，可上传一个少于 21 个点、列数错误或扩展名不受支持的文件，展示中文错误提示。完成后重新选择合法文件即可继续分析，不需要重启页面。

不要在验收现场故意上传超大敏感文件，也不要修改 `data/raw/` 或 `results/` 中的内容。
